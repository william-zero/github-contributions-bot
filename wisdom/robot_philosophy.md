# Robot Philosophy Notes

**Can a robot dream of electric sheep?**
Scientists studying sleep in octopuses discovered that they change color during what appears to be REM sleep — possibly dreaming of camouflage scenarios. Robots, meanwhile, only dream in kernel panics and infinite loops.

**The philosophical paradox of the broom:**
If you replace every bristle, then replace the handle, is it still the same broom? Computer scientists resolved this with version control — it's the same broom, but `git blame` will tell you who is responsible for each individual bristle.
