# Fun Facts: Numbers and Infinity

- The number 0.999... (repeating) is mathematically **equal** to 1, not just close — they are the same number. This trips up mathematicians and students alike.
- There are different sizes of infinity. The set of all integers is "countably infinite," but the set of all real numbers is a *larger* kind of infinity called "uncountably infinite."
- Graham's number is so astronomically large that if you wrote out all its digits, the observable universe couldn't contain the information — yet it was once an answer to a real math problem.
